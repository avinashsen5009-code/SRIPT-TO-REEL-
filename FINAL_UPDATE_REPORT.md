# Reel Studio — final Story, Structural and mobile editing update

## Changes in the existing editor

**Story:** Refined the original character instead of deleting it: lighter editorial outlines rather than thick white sticker edging, quieter facial features and expression animation, a tailored collar/lapel, optional thin glasses on a scene variant, a restrained paper/teal/copper palette, and modest scene-to-scene position/scale shifts. Desk/hand scenes, original stickmen in other styles, sketches, sticker pops, visual picker and uploaded media remain available. The changes affect Story's existing render path, including exported video.

**Structural minimalism:** Kept its charcoal grid, portrait/landscape composition, source timing and existing caption/export path. Added local, monochrome, source-gated arrangements for explicit numeric charts, dated timelines, source-grounded relation/decision/step cards, selected self-improvement tracks and the literal prop vocabulary. Reveals follow spoken word onsets, including the numeric value word; unmatched narration abstains rather than displaying an arbitrary tracker/icon. Fixed the cubic-bezier boundary case that previously yielded a small *nonzero* reveal even at progress zero, exposing unsaid chart labels early. When the 16:9 companion panel has a sourced component it uses that component or its spoken values; otherwise it no longer draws the generic ring. Manually selected treatment, pinned visuals and user media still take precedence in the primary portrait render; Structural components do not change the audio, transcription, encoder or media stitching.

**Scene editing and mobile:** The waveform remains draggable. Expanded scenes now have **Play scene**, **Preview change**, a duration-in-seconds field and **±0.25 s** buttons. Each duration edit moves a shared scene boundary: it cannot lengthen audio, and both affected scenes must remain at least 0.45 s. The single-scene duration is the actual audio duration and cannot be extended. Adjustments persist in projects and are used by preview, captions and export. The prev/next scene buttons make navigation possible without manipulating a tiny waveform handle. On narrow screens the scene list is one scrollable page, not a small nested scroll region; detailed tools still open only when a scene is expanded. Existing caption controls (including Phase 5's smaller/lower sliders), scene reorder, picker, layers, media, saved projects and five original styles remain intact.

## Honest limits

The character look is an editorial design choice, not a guarantee every user will prefer it. Structural matching is intentionally limited to explicit, recognised source cues and can abstain on unfamiliar English/Hindi/Hinglish; some generic source diagrams are schematic and should not be treated as evidence. Moving scene boundaries does **not** time-stretch, transcribe or re-align voice; users must listen to and adjust word/caption cues near edited cuts. A small late-spoken value may have very little time to reveal. The MP4 tests used a silent sample WAV: audible export, real multilingual speech alignment, playback on physical phones, battery/frame-time profiling, exact component text-collision measurement and all codecs/browsers were **not** tested. No hosted public URL was created; local browser previews are not a public deployment.

**Deployment:** [Flat ZIP](../reel-studio-final-flat.zip) contains only root-level files. Extract the files and upload them to the **root** of the GitHub Pages repository (including `index.html`, every `.js`, the stylesheets and fonts); Pages should publish `main` → `/(root)`. Optional browser speech-model weights are not bundled. This is the final requested package, not a new replacement site.
