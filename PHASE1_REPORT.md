## Deliberately incomplete Phase 1 items

- **Optional LLM director** omitted: user previously prohibited paid APIs/AI Director. A remote provider, even “optional,” would change that product constraint. The rule director remains local; its fallback is valid typography/review, not a promise to understand every language sentence.
- **Full primitive library and graph linter:** this phase provides grounded rectangles, text, links, lines, rounded boxes and counters, nominal graph bounds/font/contrast/reveal reporting. It does **not** claim verified elbow/curved/bracket/ring/bar/check/cross choreography for every graph node, true semantic Venn diagrams, pixel-level collision avoidance, universal >32px post-fit glyphs, or automatic extra scene creation. The source editor's icon library is untouched; wrong icon matches from the audit remain open for vocabulary Phase 4. Graph nodes are typography-first rather than adding wrong pictures.
- **Pattern interrupt <=8 seconds:** not enforced. Existing scene variety remains; blind flashes/cuts would harm comprehension. A source-grounded long-scene interrupt would require audio timing review.
- **Mid-range phone <12ms/frame:** unverified; desktop Chromium output is not a physical-phone benchmark. Static graph background is cached and graph planning is cached per scene, but profiling is still needed.
- **Other styles:** graph rendering is limited to Story and Explainer; the five original style renderers and the structural style are left intact rather than restyled. Auto mix chooses Story/Explainer as before.
