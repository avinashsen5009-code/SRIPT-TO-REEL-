# Phase 2 — self-improvement components (review gate)

**Added:** `self-improvement.js` extends the existing `ExplainerStyle.components` registry with 30 treatment IDs built from shared drawing families: ClaimCard, StopStrike, QuestionCard, StatShock, PatternInterrupt; BeforeAfterSplit, ThinkVsReality, BrokenChain, HeavyWeight, TangledToStraight; HabitLoop, CompoundCurve, BatteryMeter, Iceberg, BalanceScale, Funnel, Ladder/Pyramid; StreakCalendar, ProgressRing, DayTimeline, HabitGrid, StatCounter; ChecklistTick, RoutineClock, ChallengeCard, NumberedTitle; QuoteCard, IdentityStatement, MirrorMetaphor and HighlightSentence. The local parser returns a sourced treatment or null. Story and Explainer both draw these components, with their existing caption, wide-frame, media, style and export paths retained. Auto mix still selects Story or Explainer independently. Each applicable scene has a compact review control: turn this treatment off, edit up to four words per label, or restore spoken labels; these settings use the existing saved-project state.

**Fixed:** No fabricated author: a quote card needs actual quotation marks, and an author is drawn only if supplied after a dash. Progress ring needs a spoken percent, a day timeline needs at least two spoken milestones, compound curve needs an explicit 1%-daily phrase, and a streak needs a stated count. Unknown battery level remains unfilled; an explicit low-energy statement shows a low meter rather than a full one. An unspecified routine has a clock face without fabricated hour hands; checklist boxes tick only when the script explicitly says an action was completed/checked. Money renders only stated amounts. A graph edited explicitly by the user takes priority over automatic self-improvement detection. The original paid-AI-free, local-only model remains intact.

**Skipped (already existed):** `index.html:drawPrev/drawWide/drawCap`, `story-style.js:render`, `explainer-style.js:frame/caption/components`, `scene-graph.js:fromText/validate`, scene media and manual library pickers, `snap/openProj`, SRT and MP4 export. Existing multi-style presets and stickman/structural renderers were not replaced. The shared visual families avoid 30 unrelated duplicated renderers.

**Tested:** `node --check` on all first-party JS and index inline scripts; `npm test` with numeric/quote guards, registry access, inspector label save/disable and graph preservation. Headless Chromium rendered **45 sentences: 15 English, 15 Devanagari Hindi and 15 Roman Hinglish**, each once in Story and once in Explainer (90 contact-sheet frames), covering all 30 IDs, with zero page exceptions and no ID mismatches in these curated inputs. A separate silent 3-second 16 kHz WAV uploaded/decoded in Chromium: portrait 720×1280 and wide 1280×720 MP4 downloads completed and were nonempty (~1.08 MB and ~0.86 MB). 390px viewport showed no horizontal page overflow; the same portrait frame rendered identically twice at the same timestamp. A saved project reopened with its manual visual label intact; disabling the treatment returned `useSelf=false`. The 45-row nominal report is `../phase2-clarity.json` (labels, word-index order, nominal font floor and palette ratios); its **overlap field says 'not pixel-measured'**.

**Not tested:** Real Hindi/Hinglish speech recognition and word alignment; audible A/V inspection; actual MP4 playback on a physical phone; all arbitrary input strings or all codecs; CSS/browser-font variations; contact-sheet comprehension with target viewers; pixel-level text collisions; real mid-phone render timing (<12 ms); guaranteed 4.5:1 contrast for arbitrary user colors. Full Phase 5 polish is still pending.

**Known limitations:** The 30 IDs share a smaller set of visual primitives and do not guarantee a distinct polished metaphor for every sentence. Rule-based interpretation is fallible; unmatched self-improvement lines fall back to existing directions, and unclear meaning should be reviewed. Shortened visual labels can omit context; the full narration stays in the editable captions, and labels are manually editable. The curve for a spoken 1%-daily idea is **illustrative mathematical shape**, not observed growth or evidence. The graph shows no unseen daily milestones. A `PatternInterrupt` card reacts to spoken attention cues but does **not** enforce an eight-second interrupt schedule. Checklist ticks do not claim an action was done unless the script says so, so an imperative-only list stays unticked. NumberedTitle shows progress dots **only when the total number of steps is spoken**. Some template drawings (iceberg, mirror, weight, funnel) are metaphors rather than a factual diagram. Visual overlaps were reviewed in the contact sheet, not algorithmically ruled out. The earlier icon-vocabulary false matches remain for Phase 4; this phase's new prop renderers do not request those icons.
